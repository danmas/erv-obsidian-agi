### Как это работает:

1. При создании задачи LLM анализирует её и определяет, достаточно ли информации для составления плана
2. Если информации недостаточно, LLM генерирует уточняющие вопросы
3. Вопросы сохраняются в заметке Obsidian с инструкцией для пользователя
4. После ответа на вопросы пользователь запускает скрипт повторно с тем же путем
5. Система обнаруживает ответы, генерирует детальный план и создает задачу
6. История вопросов и ответов сохраняется в заметке задачи для контекста

### Пример использования:

```bash
# Создание новой задачи (может вернуть вопросы)
node index.js "Оптимизировать производительность сайта"

# Если были созданы вопросы, ответьте на них в Obsidian и запустите:
node index.js --from-obsidian "AGI-Tasks/Черновик - Оптимизировать_производительность_сайта.md"
```
