# Веб-интерфейс для управления задачами

Веб-интерфейс для работы с задачами и подзадачами из Obsidian в удобном формате.

## Возможности

- Отображение дерева задач и подзадач из папки `tests/AGI-Tasks`
- Просмотр и редактирование содержимого файлов задач
- Два режима отображения: текстовый (TXT) и форматированный Markdown (MD)
- Сохранение изменений обратно в файлы

## Установка и запуск

1. Установите зависимости:
   ```
   cd web-interface
   npm install
   ```

2. Запустите сервер:
   ```
   node server.js
   ```

3. Откройте в браузере:
   ```
   http://localhost:3000
   ```

## Использование

- Левая панель: дерево задач и подзадач
- Правая панель: просмотр и редактирование содержимого выбранного файла
- Кнопки "TXT" и "MD" переключают режим отображения
- Кликните на текст для редактирования, нажмите Esc для выхода из режима редактирования
- Кнопка "Сохранить" (или Ctrl+S) сохраняет изменения

## Структура проекта

- `server.js` - Express-сервер
- `src/` - Серверные модули
  - `file-parser.js` - Парсер файлов задач
  - `task-tree.js` - Построение дерева задач
- `public/` - Клиентские файлы
  - `index.html` - HTML-интерфейс
  - `css/styles.css` - Стили
  - `js/` - Клиентские скрипты
    - `tree.js` - Работа с деревом задач
    - `editor.js` - Редактор Markdown
