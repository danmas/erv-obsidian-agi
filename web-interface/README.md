# Веб-интерфейс для управления задачами

Веб-интерфейс для работы с задачами и подзадачами из Obsidian в удобном формате.

## ✨ Возможности

- 📋 **Дерево задач** — иерархическое отображение задач и подзадач из папки `tests/AGI-Tasks`
- ✏️ **Редактор файлов** — просмотр и редактирование содержимого файлов задач
- 👁️ **Два режима просмотра** — текстовый (TXT) и форматированный Markdown (MD) с рендерингом
- 🌙 **Темная тема** — темная тема по умолчанию с возможностью переключения на светлую
- 💾 **Автосохранение** — сохранение изменений обратно в файлы
- ⚡ **Горячие клавиши** — Ctrl+S для сохранения, Esc для выхода из режима редактирования

## Установка и запуск

1. Установите зависимости:
   ```
   cd web-interface
   npm install
   ```

2. Запустите сервер:
   ```
   node server.js
   ```

3. Откройте в браузере:
   ```
   http://localhost:3012
   ```

## 🎨 Использование

### Интерфейс

- **Левая панель** — дерево задач и подзадач с цветовой индикацией статуса
- **Правая панель** — просмотр и редактирование содержимого выбранного файла
- **Кнопка темы 🌙/☀️** — переключение между темной и светлой темами
- **Кнопки "TXT" и "MD"** — переключают режим отображения контента

### Работа с файлами

- Выберите задачу в дереве слева для просмотра содержимого
- Кликните на текст для перехода в режим редактирования
- Нажмите **Esc** для выхода из режима редактирования
- Нажмите **"Сохранить"** или **Ctrl+S** для сохранения изменений
- Изменения автоматически сохраняются обратно в файлы Obsidian

## Структура проекта

- `server.js` - Express-сервер
- `src/` - Серверные модули
  - `file-parser.js` - Парсер файлов задач
  - `task-tree.js` - Построение дерева задач
- `public/` - Клиентские файлы
  - `index.html` - HTML-интерфейс
  - `css/styles.css` - Стили
  - `js/` - Клиентские скрипты
    - `tree.js` - Работа с деревом задач
    - `editor.js` - Редактор Markdown
