# Тестирование ERV Obsidian AGI

Документация по тестированию функциональности системы управления задачами.

## 🎯 Типы тестов

### 1. Создание простой задачи
### 2. Создание задачи со сложным планом
### 3. Создание подзадачи
### 4. Создание вложенных подзадач (многоуровневая иерархия)
### 5. Работа с кириллицей

## ✅ Тест 4: Многоуровневая иерархия

### Сценарий
1. Создать главную задачу
2. Создать подзадачу для шага 0
3. Создать подзадачу для подзадачи

### Команды
```bash
# Шаг 1: Главная задача
node index.js "Запустить интернет-магазин"

# Шаг 2: Подзадача уровня 1
node expand-step.js "AGI-Tasks/Запустить интернет-магазин.md" 3

# Шаг 3: Подзадача уровня 2
node expand-step.js "AGI-Tasks/Настроить платежную систему.md" 1
```

### Ожидаемая структура

```
Запустить интернет-магазин.md (task-xxx-001, parent: null)
  └── Настроить платежную систему.md (task-xxx-002, parent: task-xxx-001)
        └── Выбрать платежный шлюз.md (task-xxx-003, parent: task-xxx-002)
```

### Критерии успеха
- ✅ Все задачи корректно связаны через `parent` и `parent_path`
- ✅ Ссылки на родительские задачи работают в Obsidian
- ✅ Каждая подзадача имеет уникальный `task_id`

## 🧪 Тестовые кейсы для автоматизации

### Позитивные тесты
1. ✅ Создание задачи с коротким названием
2. ✅ Создание задачи с длинным названием (>100 символов)
3. ✅ Создание задачи с эмодзи в названии
4. ✅ Создание подзадачи для каждого шага (1, 2, 3...)
5. ✅ Создание задачи без LLM (fallback на дефолтный план)

### Негативные тесты
1. ❌ Создание задачи без названия → Должна быть ошибка
2. ❌ Создание подзадачи с несуществующим номером → Ошибка "Шаг не найден"
3. ❌ Создание подзадачи для уже выполненного шага → Предупреждение
4. ❌ Отсутствие соединения с Obsidian API → Ошибка соединения
5. ❌ Отсутствие соединения с LLM → Fallback на дефолтный план

## 📝 Примечания

- Номера шагов начинаются с **1**
- Каждый запуск создает новую задачу (нет дедупликации)
- LLM может генерировать разные планы для одной и той же задачи
- Подзадачи НЕ используют двойные скобки `[[]]` для шагов (только простые чекбоксы)
- Родительские задачи используют `[[Ссылки]]` для возможности создания подзадач
