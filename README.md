# ERV Obsidian AGI

**Автономный AI-агент с внешней памятью в Obsidian**

## 📖 Описание

ERV Obsidian AGI — это система управления задачами с использованием искусственного интеллекта, которая интегрируется с Obsidian через REST API. Агент автоматически создает структурированные задачи и подзадачи, генерирует планы выполнения с помощью LLM и организует их в виде связанных заметок.

## ✨ Основные возможности

- **Автоматическое создание задач** — агент генерирует задачи с детальным планом выполнения
- **Генерация подзадач** — разбиение сложных шагов на более мелкие подзадачи
- **Интеграция с Obsidian** — все задачи сохраняются как заметки Markdown с фронтматтером
- **LLM-генерация планов** — использование языковых моделей для создания осмысленных планов
- **Соображения ИИ** — LLM предоставляет рекомендации, предупреждения о потенциальных сложностях и важные моменты для каждой задачи
- **Автоматическое создание заметок для шагов** — каждый шаг плана автоматически получает свою заметку с соображениями ИИ по выполнению
- **Создание задач из черновиков** — возможность написать свои соображения в Obsidian и преобразовать их в задачу с AI-планом
- **Уточняющие вопросы для сложных задач** — агент задает вопросы для уточнения деталей, если задача неоднозначная или сложная
- **Интерактивный режим** — возможность ответить на вопросы в Obsidian и получить детальный план на основе ответов
- **Связывание задач** — подзадачи автоматически связываются с родительскими задачами через Obsidian-ссылки
- **Валидные имена файлов** — автоматическая санитизация имен для корректной работы в файловой системе
- **Поддержка русского языка** — корректная работа с кириллицей

## 🏗️ Архитектура

```
erv-obsidian-agi/
├── src/
│   ├── obsidian-client.js    # Клиент для работы с Obsidian REST API
│   ├── task-manager.js        # Менеджер задач и подзадач
│   ├── llm-client.js          # Клиент для работы с LLM
│   ├── note-parser.js         # Парсер заметок (фронтматтер, чеклисты)
│   └── fix-encoding.js        # Исправление кодировок для русского языка
├── tests/AGI-Tasks/           # Папка с созданными задачами (синхронизована с папками обсидиан через kosmos-file)
├── KB/                        # База знаний
├── index.js                   # Точка входа для создания задач
└── expand-step.js             # Утилита для создания подзадач
```

### Компоненты

- **ObsidianClient** — работает с Obsidian через REST API (создание, чтение, обновление заметок)
- **TaskManager** — управляет созданием задач и подзадач, генерирует ID и структуру заметок
- **LLMClient** — взаимодействует с сервером моделей для генерации планов
- **NoteParser** — парсит Markdown-заметки (фронтматтер, чеклисты, метаданные)

## 🚀 Установка

1. Клонировать репозиторий:
```bash
git clone <repository-url>
cd erv-obsidian-agi
```

2. Установить зависимости:
```bash
npm install
```

3. Настроить `.env` файл:
```env
# Obsidian API
OBSIDIAN_API_KEY=your_api_key_here
OBSIDIAN_PROTOCOL=http
OBSIDIAN_HOST=192.168.1.254
OBSIDIAN_PORT=27123
OBSIDIAN_VERIFY_SSL=false

# LLM Server
LLM_SERVER_URL=http://usa:3002
LLM_MODEL=FAST
LLM_REQUEST_TIMEOUT=30000  # Таймаут запросов к LLM в миллисекундах
LLM_HEALTH_TIMEOUT=2000    # Таймаут проверки доступности LLM-сервера в миллисекундах

# Настройки
NODE_ENV=development
REQUEST_TIMEOUT=5000
```

## 📝 Использование

### Создание задачи

#### Стандартный способ

```bash
node index.js "Название задачи"
```

**Пример:**
```bash
node index.js "Настроить CI/CD pipeline"
```

Агент:
1. Отправит запрос к LLM для генерации плана или уточняющих вопросов
2. Если задача ясна, создаст заметку в `AGI-Tasks/Настроить CI_CD pipeline.md`
3. Добавит фронтматтер с метаданными (task_id, статус, дата)
4. Создаст чеклист с шагами выполнения

#### Интерактивный режим с уточняющими вопросами

Если задача сложная или неоднозначная, агент запросит уточнения:

```bash
node index.js "Оптимизировать производительность сайта"
```

Агент:
1. Проанализирует задачу и определит, что требуются уточнения
2. Создаст заметку с вопросами в `AGI-Tasks/Черновик - Оптимизировать_производительность_сайта.md`
3. Выведет инструкцию по заполнению ответов

После ответа на вопросы в Obsidian, запустите:
```bash
node index.js --from-obsidian "AGI-Tasks/Черновик - Оптимизировать_производительность_сайта.md"
```

Агент:
1. Прочитает ваши ответы на вопросы
2. Сгенерирует детальный план на основе полученной информации
3. Преобразует черновик в полноценную задачу с планом
4. Сохранит историю вопросов и ответов в заметке

#### Создание задачи из черновика

Вы можете создать черновик в Obsidian с вашими соображениями, а затем преобразовать его в задачу:

1. Создайте заметку в Obsidian с описанием задачи (например, `AGI-Tasks/Черновик - Настроить CI_CD.md`)
2. Запустите команду:
```bash
node index.js --from-obsidian "AGI-Tasks/Черновик - Настроить CI_CD.md"
```

Агент:
1. Прочитает ваш черновик и использует его как контекст для LLM
2. Извлечет заголовок задачи из первого заголовка в черновике
3. Если информации достаточно, сгенерирует план с учетом ваших соображений
4. Если нужны уточнения, создаст список вопросов для заполнения
5. После ответа на вопросы, преобразует черновик в полноценную задачу с планом
6. Сохранит ваши исходные соображения и историю вопросов-ответов

### Создание подзадачи

```bash
node expand-step.js "AGI-Tasks/Задача.md" <номер_шага>
```

**Пример:**
```bash
node expand-step.js "AGI-Tasks/Настроить CI_CD pipeline.md" 1
```

Агент:
1. Прочитает родительскую задачу
2. Получит шаг по указанному номеру
3. Сгенерирует детальный план для этого шага через LLM
4. Создаст подзадачу со ссылкой на родительскую задачу

```markdown

## 🧠 Соображения ИИ:

Для выбора платформы CI/CD необходимо учесть текущее расположение кода (GitHub, GitLab, BitBucket). Если код на GitHub, оптимальным выбором будет GitHub Actions благодаря интеграции. - [ ] Результат проверен

---
**Родительская задача:** Настроить CI/CD pipeline
```

## 🔧 Технологии

- **Node.js** — runtime окружение
- **Axios** — HTTP-клиент для REST API
- **Obsidian REST API** — интеграция с Obsidian
- **LLM API** — генерация планов задач

## 🔗 Интеграция

### Obsidian REST API

Проект использует [Obsidian Local REST API](https://github.com/coddingtonbear/obsidian-local-rest-api) плагин для взаимодействия с хранилищем Obsidian.

### LLM Server

Работа с моделями через собственный сервер моделей (aian-model):
- URL: `http://usa:3002`
- Модель: `FAST`
- Endpoint: `/api/send-request`

### 🌐 Веб-интерфейс

Проект включает веб-интерфейс для удобной работы с задачами через браузер:

**Особенности:**
- 📋 Дерево задач и подзадач в левой панели
- ✏️ Редактор с режимами TXT и Markdown в правой панели
- 🌙 Темная тема по умолчанию с возможностью переключения
- 💾 Автосохранение изменений в файлы

**Запуск:**
```bash
cd web-interface
npm install
node server.js
```

**Использование:**
- Откройте `http://localhost:3012` в браузере
- Выбирайте задачи в дереве слева
- Редактируйте содержимое справа
- Сохраняйте изменения кнопкой "Сохранить" или Ctrl+S
