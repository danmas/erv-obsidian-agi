# Шаг 2 Подготовка необходимых ресурсов

## 🧠 Соображения ИИ:

Чтобы подготовить ресурсы к установке PostgreSQL, выполните следующие действия:  

1. **Проверьте наличие установленных зависимостей** – для Debian/Ubuntu: `sudo apt update && sudo apt install -y build-essential libreadline-dev zlib1g-dev flex bison`; для RHEL/CentOS: `sudo yum groupinstall "Development Tools" && sudo yum install -y readline-devel zlib-devel`;  
2. **Проверьте свободное место на диске** – PostgreSQL требует минимум 1 ГБ свободного места для двоичных файлов и дополнительно 3–4 ГБ на базовый кластер; используйте `df -h` и убедитесь, что в каталоге /var/lib/postgresql пространство достаточное;  
3. **Проверьте, нет ли уже установленного PostgreSQL** – если таковое найдено, уберите его (`sudo systemctl stop postgresql && sudo apt remove postgresql*` или `sudo yum remove postgresql*`), чтобы избежать конфликтов;  
4. **Настройте пользователя и каталог** – создайте системного пользователя `postgres` (`sudo useradd -r -s /bin/false postgres`), назначьте права каталога `/var/lib/postgresql` и убедитесь, что у него необходимый доступ;  

Эти шаги гарантируют, что система готова к распаковке, компиляции и инсталляции PostgreSQL без неожиданных ошибок.
