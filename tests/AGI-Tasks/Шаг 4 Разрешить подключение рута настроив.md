# Шаг 4 Разрешить подключение рута настроив

## 🧠 Соображения ИИ:

**Что сделать**: отредактировать `/etc/ssh/sshd_config`, заменив строку `PermitRootLogin prohibit-password` на `PermitRootLogin yes`.  
**Команда**:  

```bash
sudo sed -i 's/PermitRootLogin prohibit-password/PermitRootLogin yes/' /etc/ssh/sshd_config
```  

**Важно**: сделайте резервную копию конфигурации (`sudo cp /etc/ssh/sshd_config /etc/ssh/sshd_config.bak`), проверьте синтаксис (`sudo sshd -t`), и перезапустите сервис (`sudo systemctl restart sshd`).  
**Потенциальные риски**: включение рута без пароля открывает уязвимость, поэтому убедитесь, что используете сильные ключи или ограничите IP‑адреса через `sshd_config` и `iptables`.  
**Примечание**: по умолчанию большинство дистрибутивов разрешают вход только по ключу при `PermitRootLogin prohibit-password`; изменение к `yes` позволит вход с паролем, что значительно снижает безопасность.
