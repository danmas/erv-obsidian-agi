# Шаг 4 Запустить запрос к модели через API OpenAI или в чат‑интерфейсе

## 🧠 Соображения ИИ:

Ключевой момент — создать запрос, в котором в **user**‑роле передать текст‑промпт и путь `erv_work`.  
Если используете OpenAI‑CLI, `openai chat -m gpt-4 -p "$(echo -e "Собери список файлов в каталоге $PWD/erv_work")"`.  
В API Python:  

```python
client.chat.completions.create(
    model="gpt-4",
    messages=[
        {"role":"system","content":"Ты умеешь структурировать файлы."},
        {"role":"user","content":"Перечисли все файлы и подпапки в директории /path/to/erv_work"}
    ]
)
```

Убедитесь, что переменная `OPENAI_API_KEY` выставлена, а путь корректен.  
Если каталог большой, задайте `max_output_tokens`(≈500–1000) и в ответе — список файлов (не подробные описания).  
Проверяйте наличие ошибок 40x/50x; при ошибке пропустите запрос и повторите.
