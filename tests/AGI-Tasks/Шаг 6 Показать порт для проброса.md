# Шаг 6 Показать порт для проброса

## 🧠 Соображения ИИ:

Для Docker‑образа OpenSSH добавьте в Dockerfile строку `EXPOSE 22`.  
Эта директива лишь сообщает Docker, какой порт слушает приложение, но не открывает его наружу.  
При запуске контейнера обязательно привяжите его к хост‑порту: `docker run -p 22:22 <image>`.  
Проверьте, что на хосте порт 22 не занят и разрешён фаерволом; иначе подключение будет блокироваться.
