# Шаг 3 Выполнение основных действий

## 🧠 Соображения ИИ:

1. Установите репозиторий PostgreSQL, чтобы получить актуальную версию:  
   ```bash
   sudo sh -c 'echo "deb http://apt.postgresql.org/pub/repos/apt $(lsb_release -cs)-pgdg main" > /etc/apt/sources.list.d/pgdg.list'
   wget -qO - https://www.postgresql.org/media/keys/ACCC4CF8.asc | sudo apt-key add -
   ```
2. Обновите кэши и установите нужную версию (например 15):  
   `sudo apt update && sudo apt install postgresql-15 postgresql-client-15 -y`. 3. После установки проверьте запуск сервиса:  
   `sudo systemctl status postgresql`.
