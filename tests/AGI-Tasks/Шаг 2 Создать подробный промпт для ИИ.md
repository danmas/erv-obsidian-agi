# Шаг 2 Создать подробный промпт для ИИ

## 🧠 Соображения ИИ:

1) В промпте сначала задайте контекст: «Вы – анализатор README проекта. Ваша задача – прочитать файл, распознать разделы, взять стек (tags), автора и дату последнего обновления». 2) Попросите ИИ вывести JSON‑структуру: `{ "author": "...", "last_updated": "...", "stack": [...], "summary": "короткое резюме" }`. 3) Включите уточнение, чтобы ИИ игнорировал произвольный Markdown‑хедер, использовал ключевые слова «Author», «Last updated», «Technologies» или похожие фразы. 4) Если планируете автоматизировать: создайте скрипт `parse_readme.py`, открывающий файл, передающим его содержимое в GPT‑4 via `client.chat.completions.create(...)`.
